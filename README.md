# Clothing Store 

A simple clothing store application built with React and Vite.

## Features

- Browse a collection of clothing products
- Filter products by category: Dresses, Skirts, Pants, Shoes, and Shirts
- Display product images, names, and prices
- Navigate between Shop, About, and Contact pages using React Router

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- React Router DOM

## Getting Started

1. Clone the repository.
2. Install dependencies:

   `npm install`

3. Start the development server:

   `npm run dev`

## About the Project

This project was created as part of my React learning journey to practice components, props, useState, array filtering, and React Router navigation.
